# Cartesian School

### Engineering education built around real software

**Cartesian School** is an open-source educational initiative focused on practical software engineering, computer science, AI, and modern development tools.

We build learning materials as real engineering products: version-controlled, tested, reproducible, and continuously reviewed.

🌐 **Website:** [cartesianschool.org](https://www.cartesianschool.org)

---

## What we build

Our educational projects combine:

- rigorous computer science foundations;
- practical programming;
- executable exercises and projects;
- automated validation and testing;
- professional development workflows;
- open-source engineering practices;
- modern AI-assisted software development.

The goal is not simply to teach syntax, but to teach learners how software is designed, tested, debugged, documented, and maintained.

## Python from Zero

### Python с нуля

Our flagship open-source curriculum is a complete Python learning environment built around **Python 3.14**.

👉 [Cartesian-School/python-from-zero](https://github.com/Cartesian-School/python-from-zero)

The course includes:

- 24 chapters;
- hundreds of theory lessons;
- hundreds of executable practice notebooks;
- practical projects;
- automated graders;
- interactive browser-based exercises;
- diagrams and visual explanations;
- a full book edition in PDF and EPUB;
- systematic subject-matter and methodology review.

Course website:

👉 [www.cartesianschool.org](https://www.cartesianschool.org)

## Engineering principles

We treat educational content like production software.

Our repositories use practices such as:

- Git and GitHub workflows;
- pull-request review;
- automated CI validation;
- deterministic builds;
- regression testing;
- reproducible publication pipelines;
- evidence-based content review;
- source-generated documentation;
- continuous technical and pedagogical improvement.

Code examples are expected to execute.  
Exercises are expected to be testable.  
Technical claims are expected to be verifiable.

---

## Open education

Cartesian School develops educational materials in the open whenever possible.

We believe high-quality technical education should expose learners not only to final answers, but also to the engineering process behind reliable software:

**design → implementation → testing → review → correction → release**
