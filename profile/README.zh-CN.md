### 以真实软件工程为基础的工程教育

**Cartesian School** 是一个开源教育项目，专注于实用软件工程、计算机科学、人工智能以及现代开发工具。

我们把教学材料当作真正的工程产品来建设：使用版本控制、自动化测试、可复现构建，并持续进行质量审查。

🌐 **网站：** [cartesianschool.org](https://www.cartesianschool.org)

---

## 我们在做什么

我们的教育项目结合了：

- 扎实的计算机科学基础；
- 实践型编程训练；
- 可执行的练习与项目；
- 自动化验证与测试；
- 专业的软件开发流程；
- 开源工程实践；
- 现代 AI 辅助软件开发。

我们的目标不只是教授语法，而是让学习者理解软件如何被设计、测试、调试、文档化和维护。

## 工程原则

我们像对待生产软件一样对待教育内容。

我们的代码仓库采用：

- Git 与 GitHub 工作流；
- Pull Request 评审；
- 自动化 CI 验证；
- 确定性构建；
- 回归测试；
- 可复现的发布流水线；
- 基于证据的内容审查；
- 从源文件生成文档；
- 持续的技术与教学改进。

代码示例应当能够运行。  
练习应当能够被测试。  
技术陈述应当能够被验证。

## 开放教育

Cartesian School 尽可能以开放方式开发教育内容。

我们认为，高质量的技术教育不应只展示最终答案，还应该展示构建可靠软件的完整工程过程：

**设计 → 实现 → 测试 → 评审 → 修正 → 发布**
